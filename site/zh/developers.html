让你的应用出现在人们真正会看的主屏幕上。

Sofaly 插件就是你自己的 Android TV 应用。它发送一张简短的卡片，Sofaly 以大字体和统一风格把它画在主屏幕上。

为什么要做插件

  • 摆在眼前，不在抽屉里

    你的卡片在主屏幕上，全家每次打开电视都会看到，而不是埋在应用列表里。

  • 普通的 Android 代码

    一个 ContentProvider 和一行数据，用你熟悉的 Android 来写。制作和显示卡片都免费。

  • 你的应用，你的生意

    按你的方式在 Play 发布，免费或付费都行。Sofaly 只负责画卡片；应用和客户都属于你。

两步完成

1. 声明一个带 Sofaly 动作的 provider

<provider
    android:name=".CardProvider"
    android:authorities="com.example.score.card"
    android:exported="true">
    <intent-filter>
        <action android:name="tv.sofaly.plugin.CARTAO" />
    </intent-filter>
</provider>

2. 用一行回应：标题、数值、详情和颜色

override fun query(uri: Uri, p: Array<String>?, s: String?,
                   a: Array<String>?, o: String?): Cursor =
    MatrixCursor(arrayOf("titulo", "valor", "detalhe", "cor")).apply {
        addRow(arrayOf("Match score", "2 x 1",
                       "38' second half", "#1E7A46"))
    }

保护观看者的规则

  • 你永远不直接在主屏幕上绘制：你发送文字和颜色，由 Sofaly 绘制。
  • Sofaly 绝不会向你发送任何关于用户的应用、账号或观看内容的信息。
  • 插件属于 Pro 方案，由用户选择显示哪些。
