사람들이 정말로 보는 홈 화면에 당신의 앱을.

Sofaly 플러그인은 여러분의 Android TV 앱입니다. 짧은 카드를 보내면 Sofaly가 홈 화면에 큰 글씨로, 집의 스타일대로 그립니다.

플러그인을 만드는 이유

서랍이 아닌 정면에

카드는 가족이 TV를 켤 때마다 보는 홈 화면에 있고, 앱 목록 속에 묻히지 않습니다.

SDK 없이, 비용 없이

ContentProvider 하나와 데이터 한 줄. 설치할 라이브러리도, 낼 수수료도 없습니다.

당신의 앱, 당신의 비즈니스

Play에 원하는 대로, 무료든 유료든 출시하세요. Sofaly는 카드만 그리고, 앱과 고객은 당신의 것입니다.

우리 카드 말고도 만들 수 있는 것

  • 배달주문 출발, 12분 뒤 도착.
  • 버스42번 6분 뒤 도착.
  • 헬스장오늘 수업 19시.
  • 아파트내일 9시부터 12시까지 단수.
  • 가게오늘의 할인: 커피 20%.
  • 동호회연습이 토요일로 변경.

두 단계

1. Sofaly 액션으로 provider 선언

<provider
    android:name=".CardProvider"
    android:authorities="com.example.score.card"
    android:exported="true">
    <intent-filter>
        <action android:name="tv.sofaly.plugin.CARTAO" />
    </intent-filter>
</provider>

2. 제목, 값, 세부 내용, 색상 한 줄로 응답

override fun query(uri: Uri, p: Array<String>?, s: String?,
                   a: Array<String>?, o: String?): Cursor =
    MatrixCursor(arrayOf("titulo", "valor", "detalhe", "cor")).apply {
        addRow(arrayOf("Match score", "2 x 1",
                       "38' second half", "#1E7A46"))
    }

전체 규약 읽기

시청자를 지키는 규칙

  • 홈 화면에 직접 그리지 않습니다. 텍스트와 색상을 보내면 Sofaly가 그립니다.
  • Sofaly는 사용자의 앱, 계정, 시청 내용에 대해 어떤 것도 보내지 않습니다.
  • 플러그인은 Pro 요금제의 일부이며, 어떤 것을 보일지는 사용자가 고릅니다.
