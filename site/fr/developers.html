Votre appli sur l'écran que les gens regardent vraiment.

Un plugin Sofaly est votre propre appli Android TV. Elle envoie une courte carte et Sofaly la dessine sur l'accueil, en gros caractères et dans le style de la maison.

Pourquoi faire un plugin

  • Devant, pas dans un tiroir

    Votre carte est sur l'accueil, que la famille regarde à chaque allumage, pas perdue dans une liste d'applis.

  • Du code Android ordinaire

    Un ContentProvider et une ligne de données, avec l'Android que vous connaissez déjà. Créer et afficher la carte est gratuit.

  • Votre appli, votre affaire

    Publiez sur Play comme vous voulez, gratuite ou payante. Sofaly ne fait que dessiner la carte ; l'appli et les clients sont à vous.

Deux étapes

1. Déclarez un provider avec l'action de Sofaly

<provider
    android:name=".CardProvider"
    android:authorities="com.example.score.card"
    android:exported="true">
    <intent-filter>
        <action android:name="tv.sofaly.plugin.CARTAO" />
    </intent-filter>
</provider>

2. Répondez avec une ligne : titre, valeur, détail et couleur

override fun query(uri: Uri, p: Array<String>?, s: String?,
                   a: Array<String>?, o: String?): Cursor =
    MatrixCursor(arrayOf("titulo", "valor", "detalhe", "cor")).apply {
        addRow(arrayOf("Match score", "2 x 1",
                       "38' second half", "#1E7A46"))
    }

Des règles qui protègent le spectateur

  • Vous ne dessinez jamais sur l'accueil : vous envoyez texte et couleur, Sofaly dessine.
  • Sofaly ne vous envoie jamais rien sur les applis, les comptes ou ce que regarde la personne.
  • Les plugins font partie de l'offre Pro, et la personne choisit lesquels s'affichent.
