Sofaly でできること

テレビの画面と同じく、世界ごとに整理しています。各機能のラベルは、どのプランから使えるかを示します。

十字見る聴く遊ぶアプリ家天気とスクリーンセーバー家族スマホとパソコン自分で手入れするすべての人にプライバシー

十字

誰にでもわかる整った画面を、好きなように。

15

  • 十字 Basic

    続きから・見る・聴く・遊ぶ・アプリが一列に。選んだ世界が大きくなり、その中身がすぐ下に並びます。

    使い方 ◀ ▶ で世界を切り替え、▲ ▼ で列を進み、OK で開く。

  • 続きから Basic

    していたことに戻るための場所。エピソード、局、ポッドキャスト、最後のアプリ。

    使い方 十字の最初の項目です。

  • 上部バー Basic

    検索、音声、一行の天気、時計がいつも同じ場所に。操作中は画面が広く使えるよう引っ込みます。

    使い方 ▲ で移動します。

  • クイックパネル Basic

    Wi-Fi、Bluetooth、スリープタイマー、音声出力、目覚まし、プロフィール、通知、買い物リストを、どのアプリからでも。

    使い方 戻るを長押し。

  • リモコンを、あなた流に Basic

    HOME はいつも Sofaly に戻ります。戻る長押しでクイックパネル、HOME 長押しで「家」、アプリ上で OK 長押しでそのメニュー。

    使い方 キーテスターでテレビが受け取るボタンをすべて確認できます。

  • 再生中 Basic

    再生中のジャケットとタイトルが上部のピルに。OK で一時停止・再開、OK 長押しでアプリを開きます。

    使い方 ホーム画面 › その他のオプションで有効化。

  • テーマと背景 Basic

    ダーク：選択中の作品のアート。ギャラリー：毎日メトロポリタン美術館の名画。スカイ：衛星と地図。または自分の写真や動画。

    使い方 ダーク、ギャラリー、スカイは Basic、ほかは Pro。

  • 好きなアイコンに Pro

    Play のアイコンパックを使うか、アプリのアイコンをひとつずつ変更。

    使い方 アプリ上で OK 長押し › アイコンを変更。

  • 月の満ち欠け Pro

    今夜の月と、どれだけ光っているかを、インターネットなしでテレビ自身が計算します。

    使い方 ホーム画面のカード。「見る」の最後に表示。

  • カウントダウン Pro

    選んだ日付、または次の祝日まであと何日か。

    使い方 ホーム画面のカード。「見る」の最後に表示。

  • 家のリマインダー Pro

    選んだ曜日にくり返し表示されるメモ。資源ごみの日、薬、習いごと。

    使い方 ホーム画面のカード。「見る」の最後に表示。

  • サービスの状態 Pro

    指定したアドレスをテレビが確認し、動いているかを表示。自宅サーバー、お店のサイト。

    使い方 ホーム画面のカード。「見る」の最後に表示。

  • 今日のレート Pro

    通貨、金、ビットコインの今日の値を、オープンなデータから。

    使い方 ホーム画面のカード。「見る」の最後に表示。

  • 応援チームの次の試合 Pro

    チームが次にいつ、どこと戦うかを、ホーム画面のカードで。

    使い方 ホーム画面のカード。「見る」の最後に表示。

  • ほかのアプリのカード Pro

    Sofaly のカードに加えて、提携アプリも自分のカードをホーム画面に置けます。デリバリー、バス、マンションのお知らせ。

    使い方 カードは「見る」の最後に表示されます。

見る

映画、シリーズ、そしてホームシアター級のプレーヤー。

10

  • ネットワーク Basic

    Plex、Jellyfin、Emby、PC や NAS のフォルダ（SMB、WebDAV、FTP、SFTP、NFS）、OneDrive、Dropbox、Box、Google ドライブ、UPnP、USB メモリの動画・音楽・写真。

    使い方 起動中のサーバーと USB メモリは自動で表示。ほかは「追加」から。

  • 何でも再生するプレーヤー Basic

    Dolby（AC3、E-AC3）、DTS、TrueHD の音声、Blu-ray・DVD・アニメの字幕に、Kodi や VLC なしで対応。

    使い方 再生中に ▼ で音声、字幕、字幕サイズ。

  • 止めたところから Basic

    映画もエピソードも正しい位置から再開。次のエピソードは10秒後に始まり、3話続くと「まだ見ていますか」と確認します。

    使い方 自動で動きます。

  • オープニングをスキップ Basic

    シリーズのオープニングがわかっていれば「オープニングをスキップ · OK」が表示。一度マークすればテレビが覚えます。

    使い方 初期設定でオン。

  • 好みの音声と字幕 Basic

    字幕付きオリジナルか吹き替えかを一度選べば、作品ごとに記憶。ファイルに字幕がなければインターネットから。

    使い方 テレビと映画 › 音声と字幕。

  • 見やすく、聞きやすく Basic

    黒い帯や黄色の字幕、会話を際立たせる「声をはっきり」、大きな音を抑えて小さな音を持ち上げる「音量を均一に」。

    使い方 プレーヤーの ▼ メニュー。

  • 自動字幕 Ultra

    あなたの言語の字幕がなければ、テレビがある字幕を翻訳します。

    使い方 プレーヤーの字幕メニューで選択。

  • 充実した作品ページ Ultra

    ポスター、評価、キャスト、予告編、年齢区分、シリーズ作品を、大きな文字の美しいページで。

    使い方 映画やシリーズで OK。

  • Trakt と Simkl のリスト Pro

    見たいもの、見たものを、アカウントやほかの端末と同期。

    使い方 テレビと映画 › サービスの QR でログイン。

  • ひとつの検索ですべて Basic

    映画、シリーズ、局、アプリを一度に検索し、同じ検索を YouTube、Netflix、Prime Video に引き継ぎます。

    使い方 上部バーか音声で。

聴く

ラジオとポッドキャストも、動画と同じ心配りで。

5

  • 世界中のラジオ Basic

    何千ものオープンなラジオ局を名前、国、ジャンルで。お気に入りと最近聴いた局も。

    使い方 聴く › ラジオ。

  • ポッドキャスト Basic

    名前で登録し、テレビで聴いて、止めたところから再開。

    使い方 聴く › ポッドキャスト。

  • ポッドキャストを探す Pro

    オープンなポッドキャストのカタログ全体を検索し、あなたの国で人気の番組もチェック。

    使い方 聴く › ポッドキャスト › 検索。

  • 全画面プレーヤー Basic

    大きなジャケット、チャプター、速度、エピソードの終わりで止まるスリープタイマー。

    使い方 聴く › 再生中 › プレーヤーを開く。

  • 音はイヤホンで Pro

    映画の音声をスマホのイヤホンへ同期して送信。夜でも誰も起こさずに見られます。

    使い方 プレーヤーの ▼ メニュー › スマホで音声。

遊ぶ

すべてのゲームをひとつの場所に、コントローラーの準備も万全。

6

  • ゲームをひとつの場所に Basic

    GeForce NOW、Steam Link、Moonlight、PS Remote Play、RetroArch、テレビのゲームがアプリの列から「遊ぶ」へ。クラウド、PC から、レトロ、テレビで、に分類。

    使い方 ゲーム上で OK 長押しでグループを変更。

  • 2階の PC で遊ぶ Basic

    テレビがネットワーク経由でパソコンを起こし、応答を待って Moonlight や Steam Link を開きます。

    使い方 Web パネルでパソコンを一度登録。

  • ネットワークをテスト Basic

    回線がクラウドゲームに耐えられるかを教え、弱い回線でクラウドゲームを開く前に警告します。

    使い方 遊ぶ › ネットワークをテスト。

  • ゲームコントローラー Basic

    メニューを探さずにコントローラーをペアリングし、接続中のものを上部に表示。接続したら「遊ぶ」を開く設定も。

    使い方 遊ぶ › コントローラーをペアリング。

  • ゲームモード Basic

    ゲーム中は、スクリーンセーバー、夜間フィルター、通知が試合の終わりまで待ちます。

    使い方 自動でオン。

  • Discord の仲間 Basic

    Discord サーバーで誰がオンラインで、どのゲーム中かを確認し、テレビから仲間を呼べます。

    使い方 サーバーウィジェットを有効にして番号を貼り付け。

アプリ

アプリを、意味のある順番で。

3

  • お気に入りを前に Basic

    「アプリ」にはよく開く8つを表示し、「すべてのアプリ」で残りをグリッド表示。

    使い方 十字の「アプリ」。

  • あなた好みに Basic

    どのアプリも移動、グループ化、非表示が可能。使わない初期アプリは目立たない場所へ。

    使い方 アプリ上で OK 長押し。

  • Netflix・YouTube ボタンを自由に Basic

    リモコンのアプリボタンで好きなアプリを開けます。押して開く、3秒長押しで変更。

    使い方 純正リモコンで使えます。

家

目覚まし、タイマー、自動化、スマートホーム。

10

  • テレビをつける目覚まし Basic

    時間になるとテレビが自動でつき、音量がゆっくり上がり、スヌーズもあり。目覚ましごとに名前、曜日、音、音量、アプリや最後のラジオ局も設定できます。

    使い方 戻る長押し › 目覚まし。

  • タイマーと砂時計 Basic

    名前付きタイマーを最大3つ、画面に通知。ストップウォッチも。

    使い方 「OK Google、10分後に知らせて を開いて」。

  • やさしく電源オフ Basic

    スリープタイマーは最後の5分で画面を暗くし音量を下げるので、切れた瞬間に誰も起きません。

    使い方 クイックパネルのタイマータイル。

  • 誰も見ていなければオフ Basic

    選んだ時間キー操作がないと、テレビが大きな文字で「まだ見ていますか」と尋ね、スリープします。

    使い方 画面と電源 › 操作がないとき電源オフ。

  • すぐ使えるレシピ Basic

    おやすみ、ドラマ、試合で、テレビを一度に設定（音、画面、通知）。OK で適用、もう一度で元に戻ります。

    使い方 クイックパネル。

  • 自動化 Pro

    決まった時刻、ボタンを押したとき、何かが起きたとき（映画が一時停止、みんな外出、雨が近い）に、テレビがアプリを開く、シーンを実行する、電源を切る。

    使い方 家と自動化 › 自動化。

  • テレビで Home Assistant Pro

    照明、コンセント、扇風機、カーテン、エアコン、シーンをソファから。クラウドを介さず、あなたのネットワークのサーバーと直接話します。

    使い方 HOME を長押し。

  • 玄関に誰が来た？ Pro

    ドアホンが鳴ると、カメラの画像が見ている画面の上に表示されます。

    使い方 Home Assistant と連携。

  • みんな出かけたら眠る Basic

    UniFi ルーターがあれば、家族のスマホが外出したことをテレビが察知してスリープします。

    使い方 画面と電源 › その他のオプション。

  • 音声ショートカット Basic

    「OK Google、天気予報 を開いて」で予報を読み上げ。映画、マイホーム、ボード、タイマー、電源オフも同じように開けます。

    使い方 マイクボタンを使います。

天気とスクリーンセーバー

正しい天気と、つけておきたくなるスクリーンセーバー。

10

  • 今日の天気を実測で Basic

    気温は最寄り空港の観測報から。昼夜のアイコンはテレビのある場所の日の出・日の入りに合わせます。

    使い方 ホーム画面の上部。

  • 3つのモデルで雨予報 Ultra

    降水確率は3つの気象モデル（ECMWF、ICON、GFS）の中央値。どれか1つより外れにくくなります。

    使い方 予報に自動で表示。

  • 全画面の予報 Basic

    この先24時間、降水グラフ、9日間、大気質、太陽と月。

    使い方 天気で OK。

  • 雨のお知らせ Basic

    雨が降り出しそうなとき、見ているアプリの上に通知。洗濯物を取り込む時間です。

    使い方 ホーム画面 › 天気。

  • つけておきたいスクリーンセーバー Basic

    あいさつ、大きな時計、日付、天気、通知・次の目覚まし・メッセージのカード。ギャラリーテーマでは今日の名画がゆっくり動き、焼き付きを防ぎます。

    使い方 画面と電源 › スクリーンセーバー。

  • スクリーンセーバーに自分の写真 Basic

    スマホから写真を送るか、ネットワークフォルダを選択。テレビだけが見られるフォルダに保存されます。

    使い方 QR でパネルの該当ページが開きます。

  • おはよう Basic

    目覚ましを止めると、あいさつ、時刻、予報、今日の予定。テレビが読み上げることもできます。

    使い方 「OK Google、おはよう を開いて」。

  • Google カレンダー Basic

    今日の予定と誕生日をテレビに。1つのアカウントでも、すべてまとめてでも。

    使い方 上部の日付で OK。

  • 夜間フィルター Basic

    夜は画面が暖かく、目にやさしくなります。

    使い方 画面と電源 › その他のオプション。

  • 週のまとめ Basic

    日曜の夜、アプリ別の視聴時間、使ったインターネット量、ネットワークの切断をカードで。

    使い方 画面と電源 › その他のオプション。

家族

一人ひとりのプロフィール、子どもへの配慮、来客へのおもてなし。

9

  • 一人ひとりのプロフィール Basic

    テレビの Google アカウントごとに、お気に入り、続きから、アプリの並びが別々に。

    使い方 戻る長押し › プロフィール。

  • 子どもプロフィール Basic

    プロフィールを子ども用にすると、キッズモードと就寝時間が自動でオンに。終了には保護者の PIN が必要です。

    使い方 クイックパネル › プロフィール。

  • 就寝時間 Basic

    選んだ時間帯は許可したアプリだけが開き、音量に上限がかかります。

    使い方 家族 › その他のオプション。

  • 1日の視聴時間 Basic

    選んだ人に、1日のテレビ時間の上限を。

    使い方 家族 › その他のオプション。

  • ゲストモード Basic

    来客中は、あなたのプロフィール、予定、選んだアプリを隠します。

    使い方 クイックパネルのゲストタイル。

  • ゲスト用 Wi-Fi Basic

    パスワードを一度入力すれば、ゲストはテレビの QR を読み取るだけで接続。

    使い方 家族 › ゲスト用 Wi-Fi。

  • 家族のボード Basic

    買い物リスト、ピン留めメモ、今日の誕生日を、クイックパネルとスクリーンセーバーに。

    使い方 スマホで編集、OK で項目にチェック。

  • 遠くからのメッセージ Pro

    離れて暮らす家族が、どこからでも家のテレビにメッセージや写真を送れます。

    使い方 リンクで招待。

  • ビデオメッセージ Pro

    家族からの短い動画が、送り主の名前とともにテレビに表示されます。

    使い方 スマホのパネルから。

スマホとパソコン

テレビが家の機器と話します。

8

  • スマホとパソコンのパネル Basic

    リモコン、日本語入力、テレビ画面のライブ表示、スクリーンセーバーの写真、ボード、バックアップを、家のどの端末のブラウザからでも。

    使い方 リモートアクセス › スマホからログイン（QR）。

  • テレビにお願い Pro

    「YouTube を開いて」「7分後に知らせて」「30分後に消して」と入力するか話しかければ、テレビが実行します。

    使い方 スマホのパネルで。

  • スマホから共有 Pro

    パネルをアプリとして入れると「共有」に表示。YouTube の動画やリンクはテレビで開き、テキストはメッセージになります。

    使い方 共有 › Sofaly。

  • テレビをネットワークドライブに Pro

    ドラッグしてファイルをテレビへコピー。Windows ではスマホのように「PC」に表示、Mac・Linux・スマホでは安全な WebDAV で。

    使い方 リモートアクセス › ネットワークドライブとして表示。

  • Windows のショートカット Pro

    エクスプローラーの「ネットワーク」にテレビが表示され、IP が変わってもパネルを開くショートカットが使えます。

    使い方 パネルがオンの間は常に有効。

  • 別のテレビで続きを Pro

    リビングで止めた？寝室へ送れば、もう一方のテレビが「続きから再生しますか？」と表示し、同じ位置から開きます。

    使い方 プレーヤーメニュー › 別のテレビに送る。

  • 一緒に見る Ultra

    2つの家で同じものを同時に。こちらで一時停止すれば向こうも止まり、隅にリアクションも。

    使い方 家族のテレビ同士で招待。

  • 複数の家 Ultra

    自宅と実家のテレビを、同じスマホから見守れます。

    使い方 スマホアプリから。

自分で手入れする

バックアップ、メンテナンス、診断を、覚えていなくても。

8

  • 毎晩、保護されたバックアップ Basic

    テレビを使っていない間に、あなたのパスワードで保護した完全なバックアップを作成。最新7件を保管し、毎晩復元できるかを確認します。

    使い方 システム › 自動バックアップ。

  • クラウドにもコピー Pro

    Google ドライブ、OneDrive、Dropbox、Box、NAS、USB メモリにもコピー。保護されているので、クラウド側でも読めません。

    使い方 システム › 自動バックアップ。

  • 夜間メンテナンス Basic

    寝ている間に、残りものを掃除し、権限を修復し、目覚ましを再設定します。

    使い方 自動で動きます。

  • テレビの診断 Basic

    インターネット、DNS、アプリが止まった理由を、まとめてわかりやすい言葉で。

    使い方 「OK Google、テレビの診断 を開いて」。

  • このテレビの調子 Basic

    テレビが自分の数値（起動時間、クラッシュ、目覚ましの正確さ）を測り、1画面で表示。何も家の外に出ません。

    使い方 システム › このテレビの調子。

  • セーフモード Basic

    新しいバージョンがインストール直後に不調なら、テレビはセーフモードに切り替えて抜け道を示します。

    使い方 必要なときだけ表示。

  • 変更点 Basic

    バージョンごとに変更点を説明し、リモコンで試す短いチェックリストを用意します。

    使い方 システム › 変更点。

  • 問題を報告 Basic

    何が起きたかをリモコンやスマホで伝えれば、テレビが必要な情報だけを集めます。個人情報は含みません。

    使い方 システム › 問題を報告。

すべての人に

見え方、聞こえ方、リモコンの使い方が違う人のために。

5

  • 15 言語 Basic

    ポルトガル語、英語、スペイン語、フランス語、ドイツ語、イタリア語、ロシア語、ポーランド語、トルコ語、日本語、中国語、韓国語、ヒンディー語、インドネシア語、アラビア語（右から左の画面に対応）。テレビの言語に合わせます。

    使い方 テレビと一緒に自動で切り替わります。

  • 文字サイズ Basic

    標準・大・特大をすべての画面で。文字が切れたり重なったりしないようテスト済み。

    使い方 ホーム画面 › 文字サイズ。

  • シンプルモード Basic

    大きなカード、少ない表示、アプリ名の読み上げ。リモコンが苦手な人に。

    使い方 ホーム画面 › その他のオプション。

  • 読み上げ Basic
