  • 広告ゼロ

    Basic

    無料プランでも、スポンサーのおすすめはひとつもありません。画面はあなたのもの。

  • 追跡なし

    Basic

    アカウントなし、利用分析なし、あなたが送らない限りエラーレポートも送信されません。

  • 必要なところに PIN

    Basic

    テレビを変更する操作には PIN が必要で、削除を伴う操作では再度確認します。間違いが多いと、待ち時間が毎回長くなります。

  • プライベート DNS

    Basic

    安全な DNS（DNS over TLS）を選択。応答がなければ、テレビが自動で前の設定に戻します。

  • アプリ別のインターネット

    Basic

    各アプリが使った通信量と通信先を、テレビに7日間保存します。
