みんなが本当に見るホーム画面に、あなたのアプリを。

Sofaly のプラグインは、あなた自身の Android TV アプリです。短いカードを送ると、Sofaly がホーム画面に大きな文字で、家のスタイルで描きます。

プラグインを作る理由

  • 引き出しではなく、正面に

    カードはホーム画面に置かれ、家族がテレビをつけるたびに目にします。アプリ一覧に埋もれません。

  • SDK 不要、費用なし

    ContentProvider ひとつとデータ1行だけ。私たちのライブラリも手数料も不要です。

  • あなたのアプリ、あなたのビジネス

    Play で自由に公開、無料でも有料でも。Sofaly はカードを描くだけで、アプリと顧客はあなたのものです。

2つのステップ

  1. Sofaly のアクションを持つ provider を宣言

    <provider
    android:name=".CardProvider"
    android:authorities="com.example.score.card"
    android:exported="true">
    <intent-filter>
        <action android:name="tv.sofaly.plugin.CARTAO" />
    </intent-filter>
</provider>

  2. タイトル、値、詳細、色の1行で応答

    override fun query(uri: Uri, p: Array<String>?, s: String?,
                   a: Array<String>?, o: String?): Cursor =
    MatrixCursor(arrayOf("titulo", "valor", "detalhe", "cor")).apply {
        addRow(arrayOf("Match score", "2 x 1", "38' second half", "#1E7A46"))
    }

視聴者を守るルール

  • ホーム画面に直接描くことはありません。テキストと色を送れば、Sofaly が描きます。
  • Sofaly がその人のアプリ、アカウント、視聴内容をあなたに送ることはありません。
  • プラグインは Pro プランの機能で、どれを表示するかは本人が選びます。
